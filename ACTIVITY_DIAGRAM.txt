  │                                             │                  Payment/Reference/

  ────────                          ───────                    ───────

  [Open /sales page]
       │
       ▼
  User selects sales folder
  (browser reads all files via webkitdirectory)
       │
       ▼
  User sets:
  · Download Date
  · VAT Suffix
  · Format (CSV / Excel)
  · Mode (short / full)
  · Only Checked-In toggle
       │
       ▼
  User clicks "Générer le rapport de ventes"
       │
  POST /api/sales/run ────────────► run_sales()
  (FormData: files[],                      │
   download_date, vat_suffix,        save files to temp folder
   format, mode,                           │
   only_checked_in)                  sales_report.run(config)
                                     · load all sales CSVs
                                     · filter by checked-in if set
                                     · compute commissions
                                     · generate:
                                       - SalesShort.xlsx
                                       - SalesInvoice.xlsx
                                       - Control report
                                           │
                                     cleanup temp folder
                                           │
                                     save .xlsx ─────────────► Data/Result/
                                           │                    Sales/
  ◄── {files: [{name, type}]} ─────────────┘
       │
  Show download links

  FRONTEND                          BACKEND                    STORAGE
  ────────                          ───────                    ───────

  [Open /consolidated page]
       │
       ▼
  GET /api/snapshots ──────────────► list archived snapshots
       │
  Show snapshot <select>
       │
       ▼
  User selects snapshot
  User uploads Invoice file (required)
  User uploads Sales file   (optional — auto-detects latest if empty)
  User sets: Fact Date, Period Start, Period End
       │
       ▼
  User clicks "Générer Facture Consolidée"
       │
  POST /api/consolidated/run ──────► run_consolidated()
  (FormData: snapshot_name,                │
   invoice_file, [sales_file],       load reference snapshot CSV
   fact_date, period_start,                │
   period_end)                       load invoice file
                                           │
                                     load sales file
                                     (provided or latest auto-detected)
                                           │
                                     consolidated_invoice.run()
                                     · merge payment amounts
                                       by agency + currency
                                     · merge sales commissions
                                       and balances
                                     · combine all bookings
                                       (payment + sales systems)
                                     · generate consolidated Excel
                                           │
                                     save .xlsx ─────────────► Data/Result/
                                           │                    Payment/
  ◄── {files: [{name, type}]} ─────────────┘
       │
  Show download links

  GET  /api/health                  → { status: "ok" }
  GET  /api/snapshots               → list reference snapshots
  POST /api/snapshots/upload        → upload files → archive snapshot
  POST /api/list-folder             → list CSV/Excel in a server folder
  POST /api/payment/run             → generate payment report
  POST /api/sales/run               → generate sales report
  POST /api/consolidated/run        → generate consolidated invoice
  GET  /api/results                 → list all generated output files
  GET  /api/results/download        → download a generated file
